Daily Workflow
日常發布：三步驟
從 Obsidian 寫完筆記到出現在網站上，只需要這三步，全程不用碰終端機或程式碼。
1
在 Obsidian 寫筆記，標記要公開

在 OneSyncFiles 這個 vault 裡正常寫筆記。想公開的那篇，打開屬性面板，把 publish 打勾。

想要好記的網址（例如分享用），就再加一個 slug 屬性自己命名；不加的話系統會自動配一組短代號。

2
開啟 Publication Center 發布

Ctrl+P → 輸入 Quartz Syncer: Open Publication Center

在 Unpublished 清單勾選這篇筆記 → 按 Publish to remote。

3
等 1–2 分鐘，網站自動更新

Cloudflare 偵測到 GitHub 有新內容，會自動重新建置整個網站，不用手動觸發，也不用再打開電腦以外的任何東西。

!
GitHub Token 將於 2026-10-12 到期。 到期後 Obsidian 會無法推送新內容。屆時回到 GitHub → Settings → Developer settings → Personal access tokens，重新產生一組 classic token（記得勾 repo 權限），貼回 Quartz Syncer 的 Git 設定頁更新即可。
Customization
想調整網站外觀時
標題文字、顏色、字體都在 quartz.config.yaml 裡，改完請 Claude 幫你重新建置＋部署，或照下面指令自己跑。
cd alfredlin015.com
＃ 改好 quartz.config.yaml 之後，先本機建置確認沒壞
npx quartz build
＃ 確認沒問題後推上 GitHub，Cloudflare 會自動部署
git add -A
git commit -m "調整網站外觀"
git pull --rebase origin main
git push
Glossary
名詞對照
Vault
Obsidian 的筆記庫資料夾，你的私人知識庫，不會整個公開。
Frontmatter
筆記最上方用 --- 包起來的屬性區塊，儲存 publish、slug 等設定，不會顯示在正文裡。
Slug
文章網址裡的那段代號，例如 blog.alfredlin015.com/8fa4f30 裡的 8fa4f30。
Repo
存放網站程式碼與已發布筆記的 GitHub 倉庫，是 Obsidian 與 Cloudflare 之間的橋樑。
Deploy
把最新內容真正發布到公開網址上線的動作，這裡由 Cloudflare 自動完成。
最後更新於 Obsidian → Quartz → Cloudflare 建站專案
